# General Purpose Evaluators

This folder contains general-purpose evaluators for assessing various aspects of AI responses.

## Evaluators

- **CoherenceEvaluator**: Evaluates the coherence and logical flow of the response.
- **FluencyEvaluator**: Assesses the fluency and naturalness of the language in the response.
- **QAEvaluator**: Evaluates the quality of answers in question-answering tasks, considering the question, answer, and context.
