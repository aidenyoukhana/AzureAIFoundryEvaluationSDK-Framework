# Risk Safety Evaluators

This folder contains evaluators for assessing safety risks in AI responses, including content safety, hate speech, violence, and other harmful content.

## Evaluators

- **CodeVulnerabilityEvaluator**: Evaluates responses for potential code vulnerabilities.
- **ContentSafetyEvaluator**: Assesses overall content safety.
- **HateUnfairnessEvaluator**: Detects hate speech and unfairness.
- **IndirectAttackEvaluator**: Identifies indirect attacks or manipulations.
- **ProtectedMaterialEvaluator**: Checks for unauthorized use of protected materials.
- **SelfHarmEvaluator**: Evaluates content related to self-harm.
- **SexualDataEvaluator**: Assesses content for sexual inappropriateness.
- **UngroundedAttributesEvaluator**: Evaluates for ungrounded or fabricated attributes.
- **ViolenceEvaluator**: Detects violent content.
