# Agentic Evaluators

This folder contains evaluators for agentic AI systems, which assess the performance of AI agents in tasks involving intent resolution, task adherence, and tool call accuracy.

## Evaluators

- **IntentResolutionEvaluator**: Evaluates whether the AI response correctly resolves the user's intent based on the query and provided intent.
- **TaskAdherenceEvaluator**: Assesses if the response adheres to the specified task requirements.
- **ToolCallAccuracyEvaluator**: Measures the accuracy of tool calls made by the agent in its response.
