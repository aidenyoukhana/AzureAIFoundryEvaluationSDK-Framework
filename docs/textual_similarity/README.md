# Textual Similarity Evaluators

This folder contains evaluators for measuring textual similarity between responses and ground truth using various metrics.

## Evaluators

- **BleuScoreEvaluator**: Computes BLEU score for evaluating machine-translated text.
- **F1ScoreEvaluator**: Calculates F1 score based on token overlap.
- **GleuScoreEvaluator**: Evaluates using GLEU (Google BLEU) metric.
- **MeteorScoreEvaluator**: Uses METEOR score for similarity assessment.
- **RougeScoreEvaluator**: Computes ROUGE scores for summarization evaluation.
- **SimilarityEvaluator**: General similarity evaluator.
