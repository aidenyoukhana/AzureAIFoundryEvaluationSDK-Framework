# RAG Evaluators

This folder contains evaluators for Retrieval-Augmented Generation (RAG) systems, assessing retrieval quality, groundedness, relevance, and completeness.

## Evaluators

- **DocumentRetrievalEvaluator**: Evaluates the quality of document retrieval in RAG systems.
- **GroundednessEvaluator**: Assesses whether the response is grounded in the provided context.
- **GroundednessProEvaluator**: An advanced version of groundedness evaluation.
- **RelevanceEvaluator**: Evaluates the relevance of the response to the query, considering the context.
- **ResponseCompletenessEvaluator**: Measures how complete the response is compared to the ground truth.
- **RetrievalEvaluator**: Evaluates the effectiveness of the retrieval component in RAG.
